# Third-Party Notices

## NVIDIA Agent Skills

The Skills catalog can fetch and install unmodified skills from
[NVIDIA/skills](https://github.com/NVIDIA/skills), copyright NVIDIA Corporation
and affiliates.

NVIDIA licenses documentation and skill content under
[CC BY 4.0](https://github.com/NVIDIA/skills/blob/main/LICENSE-CC-BY-4.0) and
source code under
[Apache 2.0](https://github.com/NVIDIA/skills/blob/main/LICENSE-APACHE).

Skyport does not bundle these skills. Catalog metadata is fetched when the
Skills tab is opened, and an individual skill is downloaded only when enabled.

## skills CLI

Global installation is performed with the
[Vercel skills CLI](https://github.com/vercel-labs/skills), licensed under the
MIT License. The CLI is fetched through `npx` when a skill is changed.
